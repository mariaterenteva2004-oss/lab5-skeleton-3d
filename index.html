Скелет в 3D

Интерактивная веб-презентация модели · Лабораторная работа № 5

Зажмите левую кнопку мыши, чтобы повернуть модель. Колёсиком можно изменить масштаб.

О модели: стилизованный низкополигональный скелет с анимацией ходьбы, подготовленный в Blender. Для браузера используется GLB; для просмотра на устройствах Apple подключён отдельный USDZ.

Загрузка модели…

Blender → GLB / USDZ → model-viewer · Для загрузки библиотеки требуется интернет
